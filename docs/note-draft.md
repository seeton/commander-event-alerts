# コマフェスなど「大きな統率者イベントだけ」を月1回メールする仕組みを作った

※公開前の下書き。Buttondownの審査と最終確認が終わるまでは公開しない。

コマンドフェストやコマンダーサミットには行きたい。でも、公式サイトを毎日巡回するほどではない。

その隙間を埋めるため、日本国内の大規模な統率者イベントだけを月初にまとめるサービスを作りました。

購読ページ（準備中）: https://buttondown.com/commander-events-jp

## 何が届く？

- コマンドフェスト / CommandFest
- コマンダーサミット / コマサミ / コマサミサーガ
- プレイヤーズコンベンションのコマンドゾーン

毎週の店舗イベント、一般交流会、コマンダー・パーティー、開催後のレポートは対象外です。遠征や事前申込を考えたくなる規模に絞っています。

一度知らせたら終わりではありません。10月10日のイベントが8月に分かっていれば、8月・9月・10月の月初メールに掲載します。毎日の通知はなく、対象が0件の月は送りません。

## 使い方

購読ページでメールアドレスを入力し、届いた確認メールから購読を確定するだけです。次の月初から一覧を受け取れます。やめたくなったらメール末尾の解除リンクから停止できます。

GitHubアカウントやAPIキーは不要です。メールアドレスを公開GitHubや他の購読者に見せることもありません。

## 構成は2つに絞った

GitHub Actionsが毎月1日09:15ごろに公式情報を集め、Buttondownへ配信を指示します。実行時刻は遅れることがあります。

Buttondownには登録フォーム、購読確認、解除、実際のメール配送を任せます。独自ドメインや自作SMTPは使いません。購読者情報もButtondownだけで管理します。

情報元は晴れる屋イベント検索、マジック日本公式のコマンドフェスト開催日程、プレイヤーズコンベンション公式です。記事の掲載日と大会の開催日を混同せず、開催日を確認できない告知は一覧に入れません。

ソースコード: https://github.com/seeton/commander-event-alerts

## 費用と注意点

現在のButtondownの案内では100購読者まで無料です。公開GitHub Actionsと組み合わせ、小規模に運用します。審査は必要で、利用条件や料金は将来変わる可能性があります。100人を超える場合は運用を見直します。

このサービスはWizards of the Coast、晴れる屋、BIG MAGICなどとは無関係です。情報元の表記変更や通信障害による取得漏れ・誤検出、メールの遅延や迷惑メール判定はあり得ます。参加前には必ずリンク先の公式情報を確認してください。

GitHubの定期実行が長期無活動で無効になる場合もあるため、運営側で実行状態を確認します。

「大会情報を毎日追うほどではない。でも大きな統率者イベントは見逃したくない」という人に使ってもらえたらうれしいです。
