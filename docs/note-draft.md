# コマフェスなど「大きな統率者イベントだけ」を月1回メールするサービスを作った

コマンドフェストやコマンダーサミットには行きたい。でも、公式サイトやイベントページを毎日巡回するほどではない。

この微妙な隙間を埋めるため、日本国内の大規模な統率者イベントだけを月初にメールする仕組みを作りました。

購読ページはこちらです。

https://commander-event-alerts.asaiwing1104.workers.dev/

※現在は一般購読の公開準備中です。受付開始後は、このページにメールアドレスを入れるだけで使えます。

## 何が届くのか

現在は、次のような固有イベント名を対象にしています。

- コマンドフェスト / CommandFest
- コマンダーサミット / コマサミ / コマサミサーガ
- プレイヤーズコンベンションのコマンドゾーン / Command Zone

毎週の店舗イベント、一般的な交流会、コマンダー・パーティー、開催後のレポートは送りません。「統率者」と付く予定を全部流すのではなく、遠征や事前申込を考えたくなる規模に絞っています。

## 一度知らせたイベントも、開催まで毎月知らせる

これは新着通知ではなく、月初の予定確認リストに近いサービスです。

例えば10月10日のイベントが8月に発表されていたら、8月・9月・10月の月初メールに掲載します。一度見ただけだと「後で予定を確認しよう」で忘れやすいので、開催日を過ぎるまでは毎月残す仕様にしました。

毎日メールは来ません。対象イベントがなければ送りません。

## 使い方

1. 購読ページへメールアドレスを入力
2. 届いた確認メールのリンクを開く
3. 次の月初から、開催予定イベントの一覧が届く

やめたくなったら、メール末尾の配信停止リンクを押すだけです。GitHubアカウント、リポジトリの複製、APIキーの取得などは必要ありません。

確認メールを挟むのは、他人のアドレスを勝手に登録できないようにするためです。

## 裏側は2サービスだけ

できるだけ構成を増やさず、次の2つだけにしました。

- Cloudflare Workers: 公開ページと月1回の大会検索
- Buttondown: 購読確認、購読者管理、メール配信、配信停止

WebページはCloudflareが無料で提供する `workers.dev` 上に置いています。メールアドレスはフォームからButtondownへ直接送られ、公開GitHubリポジトリやCloudflareのデータベースには保存しません。

毎月1日の09:15ごろ、Cloudflare Workersが次の公開ページを確認します。

- 晴れる屋イベント検索
- マジック：ザ・ギャザリング日本公式
- プレイヤーズコンベンション公式

固有イベント名で絞り込み、開催日を過ぎたものを除外して、Buttondownから一覧を送ります。

GmailのSMTPは使っていません。Buttondownの共用送信基盤を使うため、専用のGoogleアカウントを自動送信で動かす必要もありません。

ソースコードは公開しています。

https://github.com/seeton/commander-event-alerts

## 無料で運用できる？

小規模なうちはCloudflare Workersの無料枠と、Buttondownの最初の100購読者までの無料枠で運用できます。料金や上限は将来変わる可能性があるため、購読者が増えて無料枠を超える前には案内します。

## 注意点

これはWizards of the Coast、晴れる屋、BIG MAGICなどとは無関係の非公式サービスです。

公開ページの表記やHTMLが変わると、イベントを取得できなくなる可能性があります。すべての大型イベントを完全に網羅する保証もありません。開催日、会場、申込方法は必ずリンク先の公式情報で確認してください。

取得漏れや「この大会も対象にしたい」という提案はGitHubのIssueへお願いします。メールアドレスなどの個人情報は書かないでください。

https://github.com/seeton/commander-event-alerts/issues

## まとめ

大会情報を毎日追うほどではない。でも、コマフェスのような大きな統率者イベントは見逃したくない。

その間を埋める、小さな月次アラートです。準備が整い次第、フォームから誰でも購読できるようにします。
